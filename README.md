# Skills du CodeLab

- `ajouter-fonctionnalite` : ajoute une fonctionnalité avec ses tests et donne le vrai résultat de `pytest`.
- `revue-de-code` : relit le diff d'une branche, sans rien modifier.
- `ecrire-les-tests` : renforce les tests à partir des règles du cahier. À essayer si vous avez le temps.

Les commandes d'installation sont dans le README de votre dépôt.
