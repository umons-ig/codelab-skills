# Ajouter une fonctionnalité

## Étapes

1. Lis `AGENTS.md` et le code concerné.
2. Annonce en trois lignes maximum ce que tu vas modifier.
3. Écris le code le plus simple possible, en modifiant le moins de fichiers possible.
4. Ajoute un test par règle touchée.
5. Lance `pytest` dans le dossier de code.

## Réponse

Donne la liste des fichiers modifiés et le résultat réel de `pytest`, copié tel quel. Si tu n'as pas pu lancer `pytest`, dis-le clairement.

## Interdit

- Ajouter ce qui n'est pas demandé.
- Annoncer que cela fonctionne sans l'avoir vérifié.
- Pousser.
